# Community and help

TomYum's community lives on the **somtum.fun Discord server** (the server that runs TomYum), in its own
**tomyum-bancho** category:

| Channel | For |
|---|---|
| [#discussion](https://discord.com/channels/1512525725255860425/1559643196995149824) | Questions, setting up your server, plugins, ideas |
| [#bug-problem](https://discord.com/channels/1512525725255860425/1559643294315843746) | Something broken? Say what you did, what happened, and your logs |

**[Join the Discord server](https://discord.gg/U6Ztb3mRyz)**, then find the **tomyum-bancho** category. The
channel links above work once you've joined.

Bugs and changes to the code itself are welcome on GitHub too:
[somtum-fun/TomYum-OSS](https://github.com/somtum-fun/TomYum-OSS) (issues and pull requests; see
[Contributing](/develop/contributing)).

## Plugins to learn from

Writing a plugin? Start from the [template](https://github.com/somtum-fun/tomyum-plugin-template), and see
[Example plugins](/operations/plugins#example-plugins) for real ones that run on somtum.fun.

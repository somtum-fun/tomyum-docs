# tomyum-docs

The docs website for [TomYum-OSS](https://github.com/somtum-fun/TomYum-OSS): how to run your own osu! server
with TomYum. Built with [VitePress](https://vitepress.dev).

> TomYum is not affiliated with ppy Pty Ltd. osu! is a trademark of ppy Pty Ltd.

## Working on it

```sh
npm install
npm run dev      # http://localhost:5173, reloads as you edit
npm run build    # the site in docs/.vitepress/dist
```

Pages are Markdown under `docs/`; the sidebar is in `docs/.vitepress/config.mts`. Commands, settings and
defaults should match TomYum-OSS, so check them there before writing them down.
